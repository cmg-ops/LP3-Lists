# Lists for Light Phone 3

Expandable, infinitely nestable lists — every item can open into its
own list, as deep as you want.

**Package:** `com.dailyhobbyist.lists` · Built natively with the
[Light Phone SDK](https://github.com/lightphone/light-sdk).

## Features

- Nested lists with no depth limit; the top bar shows your full path
  (HOME/FAMILY/WIFE/GIFTS), trimmed to `…/` when long
- Move an item into any other list, or copy/paste whole items
- Per-list or whole-group checklists with a hand-drawn pencil style
- Purge checked items (one list or the whole group)
- Two-phase ABC-123 priority sorting
- Built-in 120k-word spellcheck with long-press suggestions
- Backup & restore to a shared JSON file (interchangeable with the
  Android version)
- Pure LP3 look: black, full-white, no color; fully offline

App code lives in [`tool/`](tool/); see
[`tool/README-LISTS.md`](tool/README-LISTS.md) for usage and build steps.
